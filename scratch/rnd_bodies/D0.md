TUGAS (tim Data)
Jawab dengan angka yang bisa dibuktikan dari file, bukan perkiraan:
1. Per engine: jumlah jendela, jumlah well, prevalensi positif, missing per kanal kunci (VIBLAT, SHKRSK, STUCK, CRPM, SPPA, TQA, HKLD, ROP, TFLO).
2. Sampling dan kontinuitas: laju sampel tiap kanal, panjang segmen kontinu terpanjang, jumlah gap > 1 menit. Ini menentukan apakah VMD/EMD/wavelet layak.
3. Data untuk Markov/HMM: apakah state diskret tersedia (STUCK_RT, SHKRSK, label regime) dan berapa banyak transisi per well.
4. Data untuk survival: jumlah kejadian onset per kelas, apakah ada censoring, horizon yang tersedia.
5. Data untuk anomali tanpa label: kanal mana yang bisa dipakai tanpa label, dan berapa panjang baseline bersih per well.
6. Dataset eksternal: USROP (jumlah baris, label high_MSE), Mendeley tool wear (469 jendela, 27 fitur), Volve pit/GAINLOSSTOT (ada atau tidak, sudah diparse atau belum).
7. Tabel akhir: algoritma -> kebutuhan data -> status ADA / SEBAGIAN / TIDAK ADA -> catatan.
